🔍 Kiểm tra kết nối Supabase
Chạy trước khi import để xác nhận bảng tồn tại, quyền write OK, seed-data.js đã load, và index.html có thể đọc danh mục.
⚠️ index.html không đọc được bảng categories vì thiếu RLS policy cho anon. Chạy SQL này trong Supabase → SQL Editor:
-- Cho phép người dùng chưa đăng nhập (anon) đọc danh mục
DROP POLICY IF EXISTS "categories_read_anon" ON public.categories;
CREATE POLICY "categories_read_anon" ON public.categories
  FOR SELECT TO anon USING (true);

-- Báo Supabase cập nhật schema cache
NOTIFY pgrst, 'reload schema';
📥 Nhập dữ liệu mặc định
⚠️ Import sẽ XÓA dữ liệu hiện có trong từng danh mục rồi thêm mới từ seed-data.js (tránh trùng lặp).
Import từ seed-data.js — bao gồm tất cả từ vựng, cụm từ giao tiếp và hội thoại mẫu.
